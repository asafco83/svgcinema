Submission options › restricted capability (runFullTrust) justification:
  SVGcinema Thumbnails is a File Explorer thumbnail handler for .SVGcinema project files. Windows loads its
  in-process COM thumbnail provider (svgcinema-thumbs.dll, registered with desktop2:ThumbnailHandler and a COM
  surrogate server) to draw each project's first frame. runFullTrust is required for the packaged desktop
  components: the COM server and the small app in the Start menu that explains what the add-on does. It reads only
  the files File Explorer asks it to preview and makes no network connections.

DESCRIPTION
────────────────────────────────────────
See your SVGcinema projects at a glance. With SVGcinema Thumbnails, File Explorer shows the first frame of every .SVGcinema project as its thumbnail, so you find the right animation without opening it.

Every project saved by SVGcinema carries a small picture of its first frame. This add-on lets Windows read it: open a folder of projects in Large icons and each file shows its artwork. Where Windows shows no thumbnails, as in a list or details view, your projects get the SVGcinema icon, and the Type column says "SVGcinema project".

There is nothing to set up and nothing runs in the background: Windows asks for a thumbnail when it shows a file, and that's all. The add-on works offline and never sends anything anywhere.

SVGcinema is an animation editor for the web: draw or import artwork, animate it on a keyframe timeline and export one animated SVG. Get it from the Microsoft Store or use it at svgcinema.com.
