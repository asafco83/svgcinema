Windows

Thumbnails in File Explorer. Windows 10 and 11, on regular and ARM PCs.

Download for Windows
Windows will warn you. That’s expected. Unzip it and run SVGcinema-Thumbnails-Setup.exe. The installer isn’t signed, so Windows says the publisher is unknown. Choose More info, then Run anyway. It installs for you only, with no administrator rights.

THE PLAYER

Host the player yourself.

SVGs exported with Player: External share one player. It loads from jsDelivr by default; put this file on your own server instead and add one script line before your SVGs. Use it unmodified.

cin-player.min.js The player, version {{PLAYER_VERSION}} about 24 KB Download
svgcinema-player The same player on npm and jsDelivr, every version npm i svgcinema-player

Exported files ask for the version they were made with, and every version stays on jsDelivr, so files you already shipped keep working. How the external player works →
